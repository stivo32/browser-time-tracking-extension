# ⚡ Быстрая справка: Как открыть Options Page

## 🎯 Самый быстрый способ

1. **Найдите иконку расширения** в панели инструментов Chrome (справа вверху)
2. **Правый клик** на иконке
3. Выберите **"Параметры"** (Options)

## 📍 Альтернативные способы

### Через chrome://extensions/

1. Откройте `chrome://extensions/`
2. Найдите "Browser Time Tracking"
3. Нажмите "Подробности" (Details)
4. Найдите ссылку "Параметры расширения"

### Прямая ссылка

1. Откройте `chrome://extensions/`
2. Скопируйте ID расширения
3. В адресной строке введите:
   ```
   chrome-extension://ВАШ_ID/src/options/options.html
   ```

## ⚙️ Что делать дальше

После открытия Options Page:

1. Прокрутите до секции **"Cloud Sync"**
2. В поле **"API URL"** введите: `http://localhost:8000`
3. Нажмите **"Sign In / Register"**
4. Зарегистрируйтесь или войдите на открывшейся странице

## ❓ Не вижу иконку?

1. Откройте `chrome://extensions/`
2. Убедитесь, что расширение **включено**
3. Нажмите на значок "🧩" (Расширения) в панели инструментов
4. Найдите ваше расширение и закрепите его (pin)
