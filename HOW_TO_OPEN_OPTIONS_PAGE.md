# 📖 Как открыть Options Page (Страницу настроек) расширения

## 🎯 Цель

Открыть страницу настроек расширения, чтобы:
- Указать URL бэкенда (API URL)
- Авторизоваться через веб-страницу
- Настроить синхронизацию данных

## 🚀 Пошаговая инструкция

### Шаг 1: Установите расширение (если еще не установлено)

1. Откройте Chrome
2. Перейдите на `chrome://extensions/`
3. Включите **"Режим разработчика"** (Developer mode) - переключатель в правом верхнем углу
4. Нажмите **"Загрузить распакованное расширение"** (Load unpacked)
5. Выберите папку `dist/` из вашего проекта
6. Расширение появится в списке

### Шаг 2: Найдите иконку расширения

После установки иконка расширения появится в **панели инструментов Chrome**:
- Обычно справа вверху, рядом с адресной строкой
- Иконка может быть скрыта - нажмите на значок "🧩" (Расширения) чтобы увидеть все

### Шаг 3: Откройте Options Page

**Способ 1: Через правый клик на иконке (Самый простой)**

1. Найдите иконку расширения в панели инструментов
2. **Правый клик** (или Ctrl+Click на Mac) на иконке
3. В выпадающем меню выберите **"Параметры"** (Options)
4. Откроется новая вкладка со страницей настроек

**Способ 2: Через chrome://extensions/**

1. Откройте `chrome://extensions/`
2. Найдите расширение **"Browser Time Tracking"** в списке
3. Нажмите на **"Подробности"** (Details) под расширением
4. Прокрутите страницу вниз
5. Найдите секцию **"Параметры расширения"** (Extension options)
6. Нажмите на ссылку или кнопку для открытия настроек

**Способ 3: Прямая ссылка (если знаете ID расширения)**

1. Откройте `chrome://extensions/`
2. Найдите ID вашего расширения (длинная строка под названием)
3. В адресной строке введите:
   ```
   chrome-extension://ВАШ_ID/src/options/options.html
   ```
   Замените `ВАШ_ID` на реальный ID расширения

### Шаг 4: Настройте API URL

После открытия Options Page:

1. Прокрутите страницу вниз до секции **"Cloud Sync"**
2. Найдите поле **"API URL"**
3. Введите адрес вашего бэкенда: `http://localhost:8000`
4. Поле автоматически сохранится при изменении

### Шаг 5: Авторизуйтесь

1. В той же секции "Cloud Sync" нажмите кнопку **"Sign In / Register"**
2. Откроется новая вкладка с веб-страницей авторизации
3. Зарегистрируйтесь или войдите
4. После успешной авторизации:
   - Страница автоматически закроется
   - Статус в Options Page изменится на "Connected as <email>"
   - Появятся кнопки "Sync Now" и "Sign Out"

## ❓ Частые проблемы

### Проблема: Не вижу иконку расширения

**Решение:**
1. Откройте `chrome://extensions/`
2. Найдите ваше расширение
3. Убедитесь, что оно **включено** (переключатель справа)
4. Нажмите на значок "🧩" (Расширения) в панели инструментов
5. Найдите ваше расширение и закрепите его (pin) для постоянного отображения

### Проблема: Нет пункта "Параметры" в меню

**Решение:**
1. Убедитесь, что в `manifest.json` указан `options_page`
2. Проверьте, что файл `src/options/options.html` существует
3. Пересоберите расширение: `npm run build`
4. Перезагрузите расширение в `chrome://extensions/`

### Проблема: Options Page не открывается

**Решение:**
1. Проверьте консоль браузера на ошибки (F12)
2. Убедитесь, что расширение собрано: `npm run build`
3. Проверьте путь в manifest.json: `"options_page": "src/options/options.html"`
4. Попробуйте открыть напрямую через ID расширения

## 🎯 Быстрая проверка

После открытия Options Page вы должны увидеть:

✅ Заголовок "Browser Time Tracking Settings"
✅ Секцию "Tracking Settings" с чекбоксом
✅ Секцию "Cloud Sync" с полем API URL
✅ Кнопку "Sign In / Register"
✅ Секцию "Data Management"
✅ Секцию "Statistics"

Если все это видно - вы на правильной странице! 🎉
